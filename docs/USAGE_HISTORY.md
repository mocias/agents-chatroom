# dsh-agent-room

## Windows 桌面版

安装包：`dist/Agent-Room-Setup-0.1.7-x64.exe`。使用安装向导选择目录，安装完成后从桌面或开始菜单打开 **Agent Room**。应用自带 Electron 运行时，使用者无需另行安装 Node.js；Codex / DSH / Qoder 仍需分别安装并登录。

添加 Agent 时可填写工作区的完整路径，桌面版支持选择已有文件夹。留空自动创建 `应用数据目录/workspaces/后端名称/Agent名称`；不合法的文件名字符会替换，遇到已有同名目录会追加数字。不同群聊为同一 Agent 创建独立会话，但使用相同工作区。路径失效会报错，不会静默切换目录。旧联系人保留原工作目录，不搬动已有文件；新建联系人使用独立目录。工作目录不等于文件访问权限沙箱。

添加 Codex / DSH / Qoder Agent 时自动读取真实模型列表并固定所选模型。DSH 同名模型按提供商区分。群聊创建时继承 Agent 的模型和默认推理强度；进入「会话成员 → 某位 Agent · 推理设置」可修改当前会话的推理档位，不影响其他群聊，也不能修改模型。仅显示后端报告的档位，模型不可用或切换失败会明确报错。旧版未固定模型的联系人保持兼容，可重新添加以使用新配置。Qoder 支持读取模型；若后端没有提供推理档位，则不提供调整。auto 表示后端自动选模策略。

模型查询会短暂启动对应后端；DSH 需要创建能力查询会话，不发送模型消息。能力结果缓存五分钟，重新读取或修改后端配置会更新缓存。

桌面数据目录为 `%APPDATA%\Agent Room\data`，可从应用菜单「Agent Room → 打开数据文件夹」访问。该目录与安装文件分开，升级和卸载默认保留聊天数据。桌面版与此前浏览器版的数据目录独立；如需迁移，请退出两端后将浏览器版数据目录的内容复制到空的桌面数据目录，不要覆盖已有数据。

桌面窗口关闭时会退出本应用的本地服务及会话。单实例运行；重复打开会聚焦已有窗口。服务使用随机回环端口，不会占用原浏览器版的 4318 端口。首版安装包尚未配置发布者代码签名。

开发与打包：

```powershell
npm ci --legacy-peer-deps
npm run desktop
npm run desktop:dist
npm run desktop:smoke
```

桌面烟雾测试使用隔离的 `output/desktop-smoke-*` 数据目录，不调用真实模型。

## 独立应用（第一版）

现已提供独立的本地多 Agent 聊天界面，不需要加载 DSH 插件。需要 Node.js 22 或更高版本。

```powershell
cd D:\agents-group\dsh-agent-room
npm start
```

打开 http://127.0.0.1:4318 。独立应用没有额外 npm 运行依赖，无需先安装 DSH 的 peer dependency。

- 左侧搜索栏旁「＋」添加 Agent：支持 Codex、DSH、Qoder，并可填写模型和角色设定。
- 点击联系人开始单聊；「发起群聊」弹窗一次勾选多位 Agent。
- 第一版只提供 CHAT；支持文件、图片上传、拖拽和图片粘贴。
- 左下角「外观设置」可修改主题、颜色和聊天背景图。

默认数据目录为仓库下 `.agent-room-data/`，包含联系人、会话、消息、上传文件和主题，不纳入 Git。可设置 `AGENT_ROOM_DATA` 指定其他绝对路径，`PORT` 修改端口。应用仅监听本机回环地址。

### 后端连接

先安装并登录对应 harness。应用复用本机登录状态，添加联系人或浏览记录不会启动模型；首次发送才连接后端。

在左侧底部打开「后端管理」。Windows 自动发现会查询 PATH、常见用户安装目录、系统安装记录、运行进程、应用包和快捷方式，并对相关目录进行有限深度扫描。安装到其他盘符也可以通过系统记录找到；无需写死个人路径。支持识别 Codex 启动器以及包含已知 ACP 入口的 DSH 桌面版。仅找到桌面程序、尚未识别协议入口时显示「已安装，需要配置」。发现程序不代表已登录或已通过模型对话验证。

自动发现失败时，选择后端并填写程序的完整路径或安装目录；桌面版也支持「浏览选择程序」。高级参数使用 JSON 字符串数组。保存后立即生效并持久化到数据目录中的 `backend-preferences.json`；「重新扫描」更新候选列表，「恢复自动选择」撤销手动覆盖。手动指定的文件失效时会明确报错，不会悄悄换用另一个程序。对话进行中不能修改后端。

原有数据目录中的 `backends.json` 启动配置仍兼容；界面保存的设置优先。可参考 [配置示例](standalone/backends.example.json)，其中的路径是占位符。识别到 DSH 桌面版时，会使用本机已有 ACP profile 和存在的桌面账户路由补丁；账户配置不随仓库发布。

附件最大 20 MB，背景图最大 16 MB。Codex 使用原生图片输入，ACP 后端目前收到图片/文件路径提示，读取能力取决于 harness。

## 原 DSH 插件

`dsh-agent-room` 是 **DeepSeek Harness（DSH）** 的一个插件：它在 DSH 右侧栏加一个
「Agent 群聊」tab —— 把几个 AI agent harness 放进**同一个公共房间**，让它们在你眼前互相聊天。

## 它是什么

- **一个房间，多个 harness。** codex、DSH 自己、Qoder 都能坐进同一间房，各自持有后端与工作目录。
- **公开群聊。** 房间日志对所有成员公开，你说的话所有成员都读得到。`@名字` 是**即时投递 + 强调**，不是私聊。
- **CHAT / WORK 两种模式。** CHAT 偏短回答、限制工具；WORK 放开工具、要交付物。
- **成员在 UI 里增删**，并挑选它的后端与模型；房间状态落盘，能活过一次 DSH 重启。
- **支持上传文件 / 图片**，图片以真实路径交给成员。
- **房间主题可自定义**（颜色 + 背景图），在房间面板或 DSH「设置 → 通用 → Agent 群聊外观」里改。
- **自动探测本机 harness**，结果可在「设置 → 通用 → Agent 群聊可用后端」里查看和调整。

## 安装

用 DSH 的**插件管理器**安装（不要手写 profile 的 `package.json` / `cordis.patch.yml`）：

```
plugin_manager(action: "install_bundle", target: "<本仓库绝对路径>")
```

装完若右栏没出现 tab，刷新一次页面。

**codex 后端开箱可用**（前提是本机已装好并登录 codex CLI）。其他 harness 只要探测得到就
不需要配置：DSH 桌面端用自带的 `acp` profile 起一个自己，Qoder 走 `qoder --acp`。
探测不到、或想指定启动命令时才写配置：

```yaml
backends:
  qoder:                        # harness 名，即添加成员时的选项
    agentCommand: <启动命令>
    agentArgs: <命令行参数>
```

配置里写了哪一项，哪一项就说了算；没写的部分由自动探测补上。
