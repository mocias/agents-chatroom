# 当前聊天提示词：私聊第一版

创建 Agent 或群聊不发送模型请求；首次消息才建立后端会话。

## 首次会话

`lib/room.cjs` 将身份、项目根目录的 `agent-room-skill.md`、可选角色设定和身份约束组合成 developerInstructions。Codex 在 thread/start 接收；DSH/Qoder/WorkBuddy 的 ACP 适配在首次 session/prompt 发送，成功后不重复，会话重建重新注入。本文是项目管理的会话规则，不是向用户全局技能目录安装技能。

修改技能文件后需重启服务，当前版本在进程启动时读取文件；尚未实现热更新、规则版本迁移或后端压缩后自动检测补发。

## 每轮消息

每轮仅发送该 Agent 有权接收的记录，加当前成员显示名、简短路由提醒、CHAT 模式与回复策略。记录有时间、发言者及范围，例如：

```text
[10:30:00] [公开] [@架构师] @研究员 请核对资料。
[10:30:01] [私聊：架构师 → 审查员；仅双方与用户可见] [@架构师] #审查员 请独立检查。
```

用户发言标作 `[用户]`。私聊正文保留原始 `#接收者`。接收人身份使用稳定 Agent ID 持久化；改名不改变历史访问范围。缺少 visibility 字段的旧消息保持公开。

## 输出与投递

普通文字和 @ 为公开；每块开头 #完整成员名 后接空格/换行为私聊，#用户 可私聊给用户。代码块外独占一行的 --- 分隔消息，代码块内不分隔。每块独立确定范围，不继承。

完成后先校验整批，再保存为独立气泡，随后按收件人投递；未知/歧义私聊对象拒绝整批，绝不降级公开。中断输出不投递。用户的生成预览可见，但不投递其他 Agent。用户一次提交多块且带附件时，附件只属于第一块。

实时投递、待处理队列与重放均过滤私聊，附件按消息范围进入上下文。用户 UI 可查看所有记录；这不是本机文件权限隔离，也不能阻止参与者之后主动公开其已知内容。

当前 CHAT 保留原有模式约束，完整规则不改变后端工具权限。ACP 附件仍主要传本地路径，不保证各后端具备原生图片理解能力。

## 0.1.11：统一前缀与闹钟

会话规则更新为 v2。投递给模型的正文与 UI 气泡使用 `@发送者：正文` / `#发送者：正文`，其中正文保留 @接收者 / #接收者。允许模型输出自己的完整前缀，也兼容原简写；冒充其他身份或前缀范围不一致会拒绝。原持久化正文不做破坏性迁移，展示和重放时补前缀。

每轮提供 Asia/Shanghai 当前时间及闹钟能力状态。单独消息块中的 `/alarm 时间 #或@成员 备注` 由本地工具执行，无需 MCP；创建回执仅发给创建者与用户。到期事件 kind=alarm、authorId=system，进入正常可见性过滤与历史重放；kind=system 仍是无需交给模型的 UI 状态提示。界面允许用户列出及取消当前群聊闹钟。
